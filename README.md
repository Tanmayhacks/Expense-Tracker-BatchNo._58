A menu-driven Personal Expense Tracker developed using the C programming language.

The program allows users to record expenses, manage a monthly budget, analyze spending, and permanently store expense data using file handling.

## Features

- Add new expenses
- View all expenses
- Calculate total expenses
- Category-wise expense tracking
- Search expenses using Expense ID
- Delete expenses
- Set a monthly budget
- Spending analysis
- Budget usage percentage
- Highest expense detection
- Dashboard with budget progress bar
- Permanent data storage using file handling

## Concepts Used

- C Structures
- Arrays
- Functions
- Loops
- Conditional Statements
- File Handling
- Strings
- Searching and Deletion

## How to Run

Compile:

gcc expensetracker.c -o expensetracker

Run on Windows:

.\expensetracker.exe
